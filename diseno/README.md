# Llavero ola · diseño para CNC (Gravitec)

- `propuestas/Llavero_Ola_Propuestas_Plano.png` — lámina de 10 propuestas en plano para selección
  (P01–P03 estilo foto de referencia, P04–P10 con la ola del imagotipo de Gravity Wave).
- `propuestas_plano.py` — genera la lámina. `olas.py` — utilidades de geometría y control (fresa Ø9, R4,5, zonas < 5 mm).
- `logo_ola.py` — extrae la silueta de la ola del logo como polígono.

Siguiente paso tras elegir propuesta: brief completo (acabado, espesor, canto, esquina, aristas, cantidad),
mockup con textura real y plano PDF + DXF con la skill `gravitec-fabricacion-cnc`.
